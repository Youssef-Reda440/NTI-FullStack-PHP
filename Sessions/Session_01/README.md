# Session 01 - HTML & CSS Basics

This session covers the fundamentals of HTML and CSS, including basic HTML structure, common HTML elements, forms, and basic CSS styling and layout techniques.

## Topics Covered

- HTML document structure
- Headings and paragraphs
- Images and links
- Forms and form elements
- CSS selectors
- Colors and backgrounds
- Width and sizing
- Text alignment
- `display` property
- `inline-block`
- `vertical-align`
- Basic layout and positioning
