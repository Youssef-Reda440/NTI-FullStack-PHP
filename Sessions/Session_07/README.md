# Session 07 - PHP Sessions, Requests & Validation

This session covers PHP sessions, cookies, server and request data, file uploads, input filtering and validation, regular expressions, and PHP error types.

## Topics Covered

* PHP Sessions
* `session_start()` and `session_destroy()`
* Storing and retrieving session data
* Session-based login and logout
* Session error messages
* Cookies and `$_COOKIE`
* `$_SERVER`
* HTTP request methods
* `$_REQUEST`
* File uploads using `$_FILES`
* `move_uploaded_file()`
* `pathinfo()` and file extensions
* Input filtering with `filter_var()`
* Email sanitization and validation
* Integer validation with range options
* Regular expression validation
* Regex patterns and character classes
* Regex quantifiers: `?`, `+`, `*`, `{n}`, `{n,m}`
* Regex anchors `^` and `$`
* Common regex shortcuts: `\d`, `\s`, `\w`, `\D`, `\S`, `\W`
* PHP error types
* Warning errors
* Fatal errors
* Syntax errors
* Notice errors
* Deprecated errors
* `include()` and `require()`
