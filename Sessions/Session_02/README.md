# Session 02 - CSS Styling & Layout

This session covers CSS styling and layout techniques, including borders, fonts, spacing, backgrounds, floating elements, responsive design, positioning, and stacking elements.

## Topics Covered

* CSS reset and `box-sizing`
* Borders and `border-radius`
* Custom fonts with `@font-face`
* Font size, weight, style, and family
* Margin and padding
* Background images
* `background-size`, `background-position`, and `background-attachment`
* `float` and `clear`
* Responsive Web Design (RWD)
* Media queries
* Responsive breakpoints
* Viewport height with `100vh`
* CSS positioning
* `relative`
* `absolute`
* `fixed`
* `sticky`
* Positioning with `top`, `right`, `bottom`, and `left`
* `z-index` and stacking order
