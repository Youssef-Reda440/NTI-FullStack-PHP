# Session 06 - PHP Basics

This session covers fundamental PHP concepts including arrays, functions, variable scope, constants, superglobal variables, HTTP GET/POST methods, cookies, and basic login authentication.

## Topics Covered

* Indexed arrays
* Associative arrays
* Multidimensional arrays
* `count()` and `foreach`
* Pass by value and pass by reference
* Functions and parameters
* Default parameters
* Named arguments
* `void` functions and `return`
* Functions with arrays
* Global and local scope
* `global` keyword
* `static` variables
* Constants using `const` and `define()`
* Superglobal variables
* `$GLOBALS`
* `$_GET` and `$_POST`
* HTTP GET and POST requests
* Cookies using `setcookie()`
* Reading cookies using `$_COOKIE`
* `isset()`
* Basic login authentication
* "Remember Me" functionality
* Redirecting using `header()`
* `exit()` after redirects
