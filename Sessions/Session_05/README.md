# Session 05 - PHP Basics

This session covers the fundamentals of PHP programming, including variables, data types, type casting, conditional statements, operators, and loops.

## Topics Covered

* PHP syntax and `echo`
* Variables and values
* Data types
* `gettype()`, `var_dump()`, and `print_r()`
* Automatic and manual type casting
* `if`, `elseif`, and `else`
* Short `if` (ternary operator)
* Comparison operators
* Logical operators
* Alternative `if` syntax
* `switch` statements
* Multiple `case` statements and DRY principle
* Nested `if` statements
* Assignment operators
* Increment and decrement operators
* Pre-increment and post-increment
* `for` loop
* `while` loop
* `do...while` loop
* `break` and `continue`
* Looping and conditional logic
