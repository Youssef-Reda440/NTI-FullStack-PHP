# Session 10 - PHP & MySQL CRUD and REST API

This session covers connecting PHP to MySQL, performing CRUD operations, displaying database records, and building basic REST API endpoints using PHP and JSON.

## Topics Covered

* Connecting PHP with MySQL using `mysqli`
* Creating a reusable database connection
* `mysqli_query()`
* Fetching database records
* `mysqli_fetch_assoc()`
* `mysqli_fetch_all()`
* Ordering records using `ORDER BY`
* Creating records with `INSERT`
* Reading records with `SELECT`
* Updating records with `UPDATE`
* Deleting records with `DELETE`
* Displaying database data in HTML tables
* Showing individual customer details
* Passing IDs using `GET` and `POST`
* Building Create, Read, Update, and Delete (CRUD) functionality
* Using `mysqli_num_rows()`
* Using `mysqli_affected_rows()`
* Redirecting with `header()`
* Handling HTTP request methods
* Building basic API endpoints
* Returning JSON responses with `json_encode()`
* Reading JSON request bodies with `file_get_contents('php://input')`
* Decoding JSON using `json_decode()`
* API endpoints for:

  * Getting all customers
  * Getting a customer by ID
  * Creating a customer
  * Deleting a customer
