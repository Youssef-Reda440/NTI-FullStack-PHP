# Session 03 - CSS Advanced Styling & Effects

This session covers advanced CSS styling and layout techniques, including overflow, margin collapsing, positioning, visibility, transitions, transforms, CSS units, combinators, pseudo-elements, icons, and responsive layouts.

## Topics Covered

* CSS layout with `calc()`
* `overflow`

  * `hidden`
  * `scroll`
  * `auto`
* Margin collapsing
* Positioning and layered elements
* Full-screen headers with `100vh`
* Overlay layers with `rgba()`
* `display`, `visibility`, and `opacity`
* RGB and RGBA colors
* CSS transitions
* `transition-property`
* `transition-duration`
* `transition-delay`
* `transition-timing-function`
* CSS IDs and section navigation
* Smooth scrolling with `scroll-behavior`
* CSS transforms

  * `rotate()`
  * `translate()`
  * `scale()`
  * `skew()`
* Combining multiple transforms
* Image hover effects
* Image overlays
* Relative units with `rem`
* CSS combinators

  * Descendant selector
  * Child selector `>`
  * Adjacent sibling selector `+`
  * General sibling selector `~`
* `inherit`
* Pseudo-elements

  * `::before`
  * `::after`
* Creating decorative elements with pseudo-elements
* Icons with CSS
* Responsive layouts with media queries
