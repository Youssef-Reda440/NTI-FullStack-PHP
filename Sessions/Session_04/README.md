# Session 04 - Advanced CSS

This session covers advanced CSS styling and layout techniques, including Flexbox, responsive design, CSS variables, animations, nesting, shadows, and gradients.

## Topics Covered

* CSS reset and `box-sizing`
* `display: inline-block`
* `float` and `clear`
* Flexbox layout
* `flex-direction`, `flex-wrap`, and `flex-flow`
* `justify-content` and `align-items`
* Flex item `order`
* `flex-grow` and `flex-shrink`
* Flexbox `gap`, `row-gap`, and `column-gap`
* Responsive Web Design (RWD)
* Media queries and responsive breakpoints
* CSS positioning
* Navigation layout with Flexbox
* CSS custom properties (variables)
* CSS animations and `@keyframes`
* Animation timing and iteration
* CSS `transform` and `rotateY`
* Pseudo-elements and animated `content`
* CSS nesting
* `box-shadow` and `text-shadow`
* Linear and radial gradients
* Background images and gradients
