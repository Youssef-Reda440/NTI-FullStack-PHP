# Session 08 - PHP Validation & File Handling

This session covers PHP input validation using filter functions, reusable validation rules, form validation, and basic file handling operations.

## Topics Covered

* Input validation with `filter_var()`
* Email validation using `FILTER_VALIDATE_EMAIL`
* Integer validation using `FILTER_VALIDATE_INT`
* Integer range validation
* Regular expression validation using `FILTER_VALIDATE_REGEXP`
* Input filtering with `filter_input()`
* Validating `$_POST` data
* Building reusable validation rules
* Handling validation errors
* Storing errors in `$_SESSION`
* Redirecting after validation errors
* File handling in PHP
* Reading files using `readfile()`
* Opening files using `fopen()`
* File modes: `r`, `w`, and `a`
* Reading file contents using `fread()`
* Reading files line by line using `fgets()`
* Writing to files using `fwrite()`
* Closing files using `fclose()`
